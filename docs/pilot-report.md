# Отчёт для пилота курса

`scripts/Pilot-Report.sql` выдаёт агрегаты по прогрессу, попыткам и начислениям. Скрипт работает в транзакции только для чтения. Доступ к запуску нужен только сотруднику с правом чтения соответствующих таблиц.

```powershell
psql -h localhost -p 5434 -U education_game_platform_app -d EducationGamePlatform -W -v course_slug=electrical-engineering -v "from=2026-11-01T00:00:00+07:00" -v "to=2026-12-01T00:00:00+07:00" -v min_group=5 -f .\scripts\Pilot-Report.sql
```

`from` включается в период, `to` исключается. Подставьте даты и минимальный размер группы, согласованные для пилота. Пустая таблица может означать, что в периоде нет подходящих событий или группа меньше порога.

| Таблица | Как читать |
| --- | --- |
| Переход от лекции к игре | `started_within_seven_days / read_pairs`. В знаменателе пары «студент — тема», которые прочитали все опубликованные лекции и имели полные 7 дней до конца отчёта |
| Победы с первой попытки | `first_wins / first_finished`. Первая попытка выбирается за всю историю по теме. В числителе и знаменателе учитываются итоги к концу периода |
| Итоги и таймауты | Для босса `boss_questions_timed_out / boss_questions_shown`, для аварии `crisis_timeouts / finished_attempts`. Вводный экран аварии без запуска таймера исключён |
| Начисления | По теме и причине. XP лекции относится к дате отметки чтения, игровые награды — к дате начисления |
| Покупки | Расход монет по платформе в целом. Кошелёк общий для курсов |

Даты, названия тем и версии используются для сравнения. В результатах нет email, никнеймов, ID пользователей и индивидуальных ответов. Состав курса стоит держать стабильным на время пилота, поскольку признак прочтения всех лекций опирается на текущий список опубликованных материалов.
