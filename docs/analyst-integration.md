# Пакет аналитика и новые API

## Учебный контент

Из корня репозитория на Windows запусти `.\scripts\Start-Api.ps1 -Migrate -SeedAnalyst`, затем `.\scripts\Start-Api.ps1`. При запуске в Linux передай `--migrate --seed-analyst` приложению с настроенным подключением к нужной БД.

Пакет включает 3 лекции, 36 вопросов босс-теста и 9 сценариев QTE по 4 шага. Шесть сюжетов пришли от аналитика. Для темы Кирхгофа добавлены три симуляции на баланс токов, напряжений и мощностей. Вопросы 160, 163, 174 и 178 уточнены по условиям с сохранением ключей ответов.

Импорт обновляет лекции и создаёт новые версии испытаний. Незавершённые и законченные попытки хранят ссылку на исходную версию вопросов. Идентификаторы тем и лекций, отметки чтения, открытия тем и начисленные награды сохраняются. Повторная загрузка пакета пропускает уже установленные версии.

QTE описывают действия в учебной симуляции. Сценарии с поражением током, оборванным проводом и дымом адаптированы к виртуальному стенду и требуют проверки преподавателем перед публикацией. [Рекомендации МЧС по первой помощи](https://mchs.gov.ru/deyatelnost/bezopasnost-grazhdan/universalnyy-algoritm-okazaniya-pervoy-pomoshchi_5), [оборванным проводам](https://82.mchs.gov.ru/deyatelnost/poleznaya-informaciya/rekomendacii-naseleniyu/esli-vy-obnaruzhili-oborvannye-elektricheskie-provoda), [пожару](https://04.mchs.gov.ru/deyatelnost/press-centr/novosti/5118096).

## Контракты для интерфейса

| Запрос | Данные и результат |
| --- | --- |
| `GET /api/auth/registration` | Два героя, герой по умолчанию, минимум пароля, статус регистрации и текущий текст согласия с версией |
| `POST /api/auth/register` | `email`, `password`, `displayName`, `heroKey` (по умолчанию `phase`), `acceptConsent`, `consentVersion`. С `signIn: true` сразу устанавливает cookie |
| `GET /api/me` | Дополнительно возвращает свой email, героя, версию и дату согласия, XP до следующего разряда |
| `PUT /api/me/nickname`, `PUT /api/me/hero` | `displayName` или `heroKey`. Успех — 204 |
| `PUT /api/me/password`, `DELETE /api/me` | `currentPassword` и `newPassword` либо `password` для удаления. Успех — 204 |
| `POST /api/auth/forgot-password` | `email`. При настроенной почте ответ 202 одинаковый для существующих и неизвестных адресов |
| `POST /api/auth/reset-password` | `userId`, `token`, `newPassword`. Успех — 204. Ссылка действует час и перестаёт работать после смены пароля |
| `GET /api/instructions`, `GET /api/public/courses`, `GET /api/public/courses/{courseId}/topics` | Публичная инструкция и карточки тем. Для лекций, прогресса и испытаний нужен вход |
| `GET /api/me/courses/{courseId}/journey` | `destination` (`Attempt`, `Lesson`, `Topic`, `Completed` или `Topics`), нужные ID и итоговая статистика для завершённого курса |
| `POST /api/me/courses/{courseId}/completion/claim` | После прохождения курса 200 со статистикой для первого вызова, 204 для повторных, 409 до завершения |

У попытки дополнительно есть `bossIcon`, `bossIntro`, `currentQuestion.calculationHint`, `nextTopicId` и `completedCourseId`. Для новой победы с повышением сервер возвращает `reward.newRank`. Срок ответа берётся из `currentQuestion.expiresAt`. В новых босс-тестах это 50 секунд, старые попытки используют прежние настройки.

Изменяющие запросы требуют cookie CSRF и заголовок `X-CSRF-TOKEN` из `GET /api/auth/csrf`. Обновляй токен после изменения сессии. Герой хранится отдельно от выбранного маскота и экипированного скина.

## Настройки запуска

- В обычном окружении регистрация требует согласие. Передай утверждённый текст и его версию через `Account__ConsentText` и `Account__ConsentVersion`. Без них регистрация возвращает 503. В `Development` проверка по умолчанию отключена для совместимости с текущей формой. Старые ники сохранены, новые и изменённые проверяются на уникальность без учёта регистра.
- Для почты укажи `PasswordMail__Host`, `PasswordMail__Port` (по умолчанию 587), `PasswordMail__From`, при необходимости `PasswordMail__Username` и `PasswordMail__Password`. SMTP должен поддерживать STARTTLS. `PasswordMail__ResetPageUrl` указывает на HTTPS-страницу сброса. Ссылка передаёт `userId` и `token` во фрагменте. Почтовая очередь хранится в памяти процесса. В Docker передай переменные в окружение сервиса API.
- Удаление удаляет аккаунт и связанные записи из рабочей базы и завершает сессии. Политика хранения резервных копий настраивается при развёртывании.
- Формы регистрации, восстановления и настроек используют эти контракты. Клиент обрабатывает гостевой каталог, выбор героя и итог курса, а лекции отображает через Markdown с поддержкой формул.
