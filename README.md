# edtech-gamification-platform

Образовательная платформа по электротехнике: теория, тест с боссом и сценарии аварий.
Стек: C# / ASP.NET Core / .NET 10, EF Core 10, PostgreSQL 18; фронтенд — HTML, CSS и JavaScript.

## Запуск на своём ПК

Открыть `EducationGamePlatform.sln` в Rider. Основная локальная база — `EducationGamePlatform` на `localhost:5434`.
Подключение уже настроено в исключённом из Git `appsettings.Local.json`.
После получения обновления, из корня репозитория:

```powershell
.\scripts\Start-Api.ps1 -Migrate -SeedDemo
.\scripts\Start-Api.ps1
```

Открыть **http://localhost:5244/** — здесь теперь работает фронтенд, обслуживаемый тем же приложением, что и API.
Отдельный сервер фронтенда и npm для запуска не нужны. Вместо второго шага можно запустить HTTP-профиль в Rider.
Для нового подключения — [инструкция по БД](docs/local-database.md).

## Что работает

- Регистрация, вход, восстановление входа по cookie, выход и CSRF-защита.
- Главная страница, профиль с разрядом и полосой XP, история попыток, правила игры.
- Три демонстрационные темы: лекция, банк из 10 расчётных вопросов, три аварийных сценария на каждую тему.
- Первое прочтение лекции даёт 20 XP и открывает испытания.
- Босс: 7 вопросов, 4 варианта, 60 секунд на вопрос; победа при 5 верных, поражение при третьей ошибке.
- Авария: 4 шага по 3 действия; общий таймер 60 секунд, +10 за верный выбор, −10 за неверный. Неверный вариант блокируется без смены шага.
- Серверные таймеры, восстановление попытки после обновления страницы и автоматическое завершение истёкших попыток.
- Первая победа по теме даёт 100 XP / 30 монет; без ошибок — ещё 50 XP / 20 монет. Повторная победа в любом режиме — 25 XP / 7 монет.
- Победа открывает следующую тему; поражение сохраняет уже достигнутый прогресс. Процент курса считается по пройденным темам.
- Проверки владельца, атомарное сохранение ответов/прогресса/наград, защита от повторной обработки запроса и одновременных запусков.
- Миграции БД, OpenAPI, health checks, интеграционные тесты, Docker и GitHub Actions.

Демонстрационный учебный материал требует проверки преподавателем. Награды и пороги разрядов предварительные;
они находятся в секции `Game` файла `src/EducationGamePlatform/appsettings.json`.
Редактор содержания, восстановление пароля по почте, магазин, кастомизация и лабораторный симулятор не реализованы.

## Структура

```text
frontend/                                  # интерфейс, API-клиент, экраны
src/EducationGamePlatform/                  # приложение ASP.NET Core
  Domain/                                  # сущности
  Features/Auth, Profile, Catalog, Game/    # маршруты и логика
  Infrastructure/                          # CSRF, пользователь, health checks
  Persistence/                             # EF Core, миграции, демоданные
tests/EducationGamePlatform.IntegrationTests/ # проверки API, БД и обновления схемы
docs/                                      # контракты и инструкции
requests/EducationGamePlatform.http         # запросы для Rider
scripts/                                   # настройка и запуск Windows
deploy/                                    # Dockerfile, Compose, пример .env
```
