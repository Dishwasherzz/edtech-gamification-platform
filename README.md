# edtech-gamification-platform

Образовательная платформа по электротехнике: теория, тест с боссом и сценарии аварий.
Стек: C# / ASP.NET Core / .NET 10, EF Core 10, PostgreSQL 18; фронтенд — HTML, CSS и JavaScript.

## Запуск на своём ПК

Открой `EducationGamePlatform.sln` в Rider. Локальное подключение задаётся в `appsettings.Local.json`.
На рабочем ПК проекта используется база `EducationGamePlatform` на `localhost:5434`.
После получения обновления, из корня репозитория:

```powershell
.\scripts\Start-Api.ps1 -Migrate -SeedAnalyst
.\scripts\Start-Api.ps1
```

Открыть **http://localhost:5244/** — здесь теперь работает фронтенд, обслуживаемый тем же приложением, что и API.
Если встроенный браузер сохраняет старый интерфейс, открыть **http://127.0.0.1:5244/** — это то же приложение и та же БД.
Отдельный сервер фронтенда и npm для запуска не нужны. Вместо второго шага можно запустить HTTP-профиль в Rider.
Для нового подключения — [инструкция по БД](docs/local-database.md).

Для локального пилота запустить `.\scripts\Start-Api.ps1 -Migrate -SeedPilot`, затем `.\scripts\Start-Api.ps1`.
Пилот обновляет лекцию первой темы и добавляет версии испытаний по последовательным и параллельным цепям. Для актуального курса используй `-SeedAnalyst`. Старые вопросы, попытки и отметки чтения остаются в базе.

## Что реализовано на бэкенде

- **Аккаунты и профиль.** Регистрация с уникальным email и ником, выбор одного из двух героев, запись версии и даты согласия. Вход и выход работают через cookie с CSRF-защитой. API поддерживает смену ника, героя и пароля, восстановление по одноразовой ссылке и удаление аккаунта с подтверждением паролем.
- **Каталог и материалы.** Гости могут получить инструкцию и карточки тем. Лекции и испытания доступны после входа с учётом прогресса. Пакет аналитика содержит 3 лекции, 36 расчётных вопросов и 9 аварийных сценариев. Импорт сохраняет историю попыток и отметки чтения.
- **Босс-тест.** Сервер выбирает 7 вопросов из банка, даёт 50 секунд на вопрос в пакете аналитика и снимает 20% здоровья босса за верный ответ. Пять верных ответов дают победу, третья ошибка завершает попытку.
- **Авария (QTE).** Четыре шага по три варианта действий. Общий таймер начинается с 60 секунд. Верный выбор добавляет 10 секунд, неверный отнимает 10 секунд и блокирует этот вариант. Сервер сохраняет попытки и отдаёт результаты с разбором.
- **Прогресс и награды.** Первое прочтение лекции даёт 20 XP и открывает испытания. Первая победа открывает следующую тему и даёт 100 XP и 30 монет. Безошибочная первая победа добавляет 50 XP и 20 монет. Первые три повторные победы по теме дают по 25 XP и 7 монет. API показывает прогресс, разряд и историю, подсказывает, откуда продолжить, и выдаёт итог курса для одноразового показа.
- **Маскоты и скины.** Каталог маскотов, выбор спутника, реакции на ход и результат испытания, гардероб, экипировка скинов и магазин с покупками за монеты. Повтор одного запроса покупки защищён от двойного списания.
- **Хранение и проверка.** PostgreSQL и миграции EF Core, проверка владельца попытки, сохранение результата и награды в одной транзакции, OpenAPI в режиме разработки, проверки состояния приложения, интеграционные тесты и GitHub Actions.

Интерфейс использует API для согласия, восстановления доступа, настроек аккаунта, выбора героя, магазина и завершения курса. Для публичной регистрации нужен утверждённый текст согласия. Для отправки ссылок восстановления требуется SMTP. [Настройки и контракты API](docs/analyst-integration.md).

Учебные материалы требуют согласования с преподавателем. Пороги разрядов и параметры наград заданы в секции `Game` файла `src/EducationGamePlatform/appsettings.json`.

## Структура

```text
frontend/                                  # интерфейс, API-клиент, экраны
src/EducationGamePlatform/                  # приложение ASP.NET Core
  Domain/                                  # сущности
  Features/                                # аккаунты, профиль, каталог, испытания и косметика
  Infrastructure/                          # CSRF, пользователь, health checks
  Persistence/                             # EF Core, миграции и учебные данные
tests/EducationGamePlatform.IntegrationTests/ # проверки API, БД и обновления схемы
docs/                                      # контракты и инструкции
requests/EducationGamePlatform.http         # запросы для Rider
scripts/                                   # настройка и запуск Windows
deploy/                                    # Dockerfile, Compose, пример .env
```
